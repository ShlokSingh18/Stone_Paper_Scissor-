# 🎮 Stone Paper Scissor Game

A modern **Stone Paper Scissor** game built with **Django** featuring a futuristic cyberpunk-inspired user interface.

## ✨ Features

- 🎮 Stone, Paper & Scissor gameplay
- 🏆 Score tracking
- 💻 Built with Django
- 🎨 Responsive Cyberpunk UI
- ⚡ Smooth animations
- 📱 Responsive Design

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/your-username/stone-paper-scissor.git
```

### Move into the project

```bash
cd stone-paper-scissor
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate virtual environment

Windows

```bash
venv\Scripts\activate
```

Linux / macOS

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the server

```bash
python manage.py runserver
```

Open your browser:

```
http://127.0.0.1:8000/
```
